# Travel Website

A simple and responsive travel website created using HTML, CSS, and JavaScript.

## Features

* Home page
* Destinations
* Travel packages
* Image gallery
* About Us
* Contact page
* Responsive design

## Technologies Used

* HTML
* CSS
* JavaScript
* Docker
* Nginx
* Jenkins
* GitHub

## Run with Docker

Build the Docker image:

```bash
docker build -t travel-website .
```

Run the container:

```bash
docker run -d --name travel-website-container -p 80:80 travel-website
```

Open the website:

```text
http://localhost
```
